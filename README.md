# Trabajo Práctico - Perfiles de Impresión 3D

## Descripción

Este repositorio contiene los perfiles de impresión realizados en OrcaSlicer para una actividad práctica de impresión 3D.

Para el trabajo se utilizaron dos modelos STL y se planteó una situación de uso diferente para cada uno.

## Perfiles

### Perfil 1 - Brain Frieza

Este modelo fue pensado como una figura decorativa. Se escaló al 53% y se dividió en dos partes para facilitar su impresión y reducir la cantidad de soportes necesarios.

### Perfil 2 - Optical Illusion

Para este modelo se priorizó la calidad de las superficies y la definición de las formas, utilizando una configuración enfocada en obtener una mejor terminación.

## Configuración utilizada

* Impresora: Creality Ender-6
* Boquilla: 0,4 mm
* Material: PLA Hellbot
* Temperatura del hotend: 205 °C
* Temperatura de cama: 62 °C

## Contenido del repositorio

* Perfil de OrcaSlicer para Brain Frieza.
* Perfil de OrcaSlicer para Optical Illusion.
* Documentación y justificación de las configuraciones utilizadas.
